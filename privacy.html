🔒 隐私政策

最后更新：2025年1月

本应用不收集任何用户个人信息，所有数据保存在设备本地。

1. 数据收集

本应用（广东高考英语听说练习软件）不收集、不存储、不传输任何用户的个人信息。应用运行过程中产生的所有数据（包括练习记录、成绩、设置等）均保存在用户设备的本地存储（localStorage）中，不会上传到任何服务器。

2. 数据存储

所有用户数据存储在浏览器的 localStorage 中，包括：

- 练习进度记录

- 历史成绩

- 应用设置

这些数据仅存在于用户设备上，用户可随时通过应用内的"清除所有记录"功能删除全部数据。

3. 网络访问

应用在以下情况下会访问网络：

- 检查更新：从 GitHub Pages、jsdelivr CDN、Gitee 等公开渠道获取版本信息

- 资源搜索：用户主动搜索听说资源时，跳转到搜索引擎

- 语音功能：使用浏览器内置的 Web Speech API 进行语音合成和识别（由浏览器处理，不经过本应用服务器）

以上网络访问不涉及任何个人信息的传输。

4. 第三方服务

本应用不集成任何第三方分析、追踪或广告服务。更新检查和资源托管使用 GitHub Pages、jsdelivr CDN 和 Gitee 等公开代码托管平台。

5. 权限说明

应用可能请求以下浏览器权限：

- 麦克风权限：用于语音识别练习（Part A/B/C 的口语部分），仅在用户主动练习时使用

- 剪贴板权限：用于复制QQ号等反馈信息

以上权限均为功能性需要，用户可随时在浏览器设置中撤销。

6. 反馈与联系

如对隐私政策有任何疑问，可通过应用内的反馈功能添加QQ好友联系开发者。

7. 政策更新

本隐私政策可能会随应用版本更新而调整，更新后将在应用内通知用户。
